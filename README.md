# PakBook — component-wise React project

## Run
1. Extract the folder and open it in VS Code.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the localhost URL shown in the terminal.

## Component map
- `src/App.jsx` — app state and page composition (the parent/controller).
- `src/components/Avatar.jsx` — reusable profile avatar.
- `src/components/Stories.jsx` — stories row.
- `src/components/Post.jsx` — post card, likes, and comments.
- `src/components/ProfilePage.jsx` — profile page and tabs.
- `src/components/FriendsPage.jsx` — friends directory.
- `src/components/ExplorePage.jsx` — Groups, Marketplace, Events, Gaming, Saved, Memories, Pages, Feeds.
- `src/data/mockData.js` — demo users, captions, images, navigation, and 32 seeded posts.
- `src/styles.css` — shared design system, themes, and responsive styling.
- `src/main.jsx` — React entry point.

## Note
This is a frontend demo. Images/video samples are remotely hosted and require internet access. Messages and posts are local demo state; they are not saved to a real backend.
